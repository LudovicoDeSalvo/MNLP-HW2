# OCR Post-Correction and Evaluation Pipeline

## Introduction

This project provides a comprehensive, portable pipeline for fine-tuning, evaluating, and analyzing Language Models (LLMs) on the task of OCR Post-Correction. The primary goal is to take noisy text generated by Optical Character Recognition (OCR) systems and use a fine-tuned LLM to clean it up, restoring it to its original, correct state.

The entire pipeline is managed through an interactive command-line interface and is designed for easy setup and portability between different environments.

## Features

This project includes a wide range of features designed for robust model development and analysis:

* **Dual Model Support:** The pipeline is pre-configured to work with two different models, `TinyLlama` and `sapienzanlp/Minerva-350M-base-v1.0`, allowing for easy comparison.
* **Efficient Fine-Tuning:** Utilizes Parameter-Efficient Fine-Tuning (PEFT) with LoRA and 8-bit quantization via `bitsandbytes` to make training accessible on consumer-grade GPUs.
* **Advanced Data Pre-processing:**
    * Features a one-time, Gemini-powered data preparation step that intelligently splits long documents into semantically coherent chunks, creating high-quality training data that respects model context limits.
    * Saves the processed, chunked dataset locally to a `preprocessed_chunks.json` file, making subsequent training runs fast and efficient.
* **Multi-Faceted Evaluation Suite:**
    * **Standard Metrics:** Automatically calculates Levenshtein distance and Character Error Rate (CER) for a quantitative measure of performance.
    * **LLM-as-a-Judge:** Uses the powerful Google Gemini API to provide a nuanced quality score (from 0-30 for Italian, 1-5 for English) on the model's corrections, using advanced Chain-of-Thought prompting for more reliable results.
    * **Interactive Human Correlation:** A dedicated menu option allows a human user to score model outputs in real-time. The script then compares the human scores against the Gemini judge's scores and calculates Pearson Correlation, Mean Absolute Error (MAE), and Cohen's Kappa to validate the automated judge.
* **Fully Portable and Automated:**
    * **Automatic Path Detection:** The project requires no manual path configuration. It automatically detects its root directory at runtime, making it work seamlessly after a `git clone` in any environment (local machine or Google Colab).
    * **Interactive CLI:** All major tasks (pre-processing, training, evaluation) are managed through a user-friendly command-line menu.
* **External Data Evaluation:** Includes a companion Google Colab notebook (`MNLP_Test(2).ipynb`) designed to run the trained models on any external CSV file you provide, separate from the main project's dataset.

## How to Run

Follow these steps to set up and run the project.

#### 1. Setup
1.  **Clone the Repository:**
    ```bash
    git clone <your-repository-url>
    cd <repository-name>
    ```
2.  **Add API Keys and Tokens:**
    * Create a folder named `general_utils`.
    * Inside `general_utils`, create a file named `google_api.txt` and paste your Google Gemini API key into it. (Provided in Google Colab)
    * Inside `general_utils`, create another file named `hf_token.txt` and paste your Hugging Face access token into it. (Provided in Google Colab)

3.  **Install Dependencies:**
    * Launch the application:
        ```bash
        python3 main.py
        ```
    * From the main menu, select **Option 5: Install/Update Requirements** to install all necessary Python packages from `requirements.txt`.

#### 3. Recommended Workflow
Once the setup is complete, use the interactive menu in the following order:

1.  **Run Pre-processing (Menu Option 1):**
    * Select `1. Pre-process Dataset with Gemini`.
    * Choose the dataset you want to process (e.g., Italian).
    * This is a **one-time step** per dataset. It will use the Gemini API to create the high-quality `preprocessed_chunks.json` file needed for training.

2.  **Train a Model (Menu Option 2):**
    * Select `2. Train Model(s)`.
    * Choose the dataset (which now has pre-processed data).
    * Select the model you wish to train (e.g., TinyLlama).
    * The script will load the pre-processed chunks and begin fine-tuning.

3.  **Evaluate a Model (Menu Option 3 or 4):**
    * Select `3. Evaluate Model(s)` to run a full evaluation on the original documents.
    * Select `4. Human vs. Gemini Correlation` to run the interactive scoring workflow.
